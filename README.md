## Overview

**RajPeakPortal** is a premium, mountain-themed authentication portal with a stunning glassmorphism design. It features a compulsory mountain landscape background, a translucent blue glass card with backdrop blur, interactive 3D buttons, and complete signup/login functionality with local storage persistence.

### Objectives
- **Mountain Theme:** Compulsory landscape background with glassmorphism
- **Premium Design:** Blue translucent glass card with blur effect
- **Dual Authentication:** Sign up and Sign in functionality
- **User Management:** LocalStorage for user database
- **Session Management:** Secure session storage
- **Personalized Dashboard:** Welcome message with user name
- **Interactive UI:** 3D tilt buttons with dynamic shadows

## Key Features

### Authentication System
- **Sign Up:** Create new account with username and password
- **Sign In:** Login with existing credentials
- **Session Management:** Secure session storage
- **Logout:** Clear session and return to login
- **User Persistence:** LocalStorage for user database
- **Remember Me:** Toggle checkbox for convenience

### Visual Design
- Mountain landscape background with gradient overlay
- Glassmorphism card with backdrop blur
- Translucent blue glass effect
- Yellow/lime accent button (#d4ed31)
- Outfit font for modern typography
- Avatar icon in circular frame

### Dashboard
- Personalized welcome message
- Secure Summit Auth widget
- Mountain Landscape View widget
- RajPeakPortal Access widget

### Notifications
- Toast notifications for all actions
- Auto-dismiss after 3 seconds
